# Settle the Score

A lightweight, customizable two-team scorekeeper built for GitHub Pages.

## Features

- Tap either score to add a point
- Plus/minus controls for both teams
- Editable team names and colors
- Six curated font styles, including Death Metal
- “Make it Metal” instant theme
- Swipe up to add or down to subtract
- Preset color swatches plus full color pickers
- Automatic, stacked, or side-by-side layout
- Optional negative scores
- Team swap and one-tap reset
- Preferences and scores saved locally in the browser
- Responsive mobile and desktop design
- Native full-screen button with Home Screen installation fallback

## Publish on GitHub Pages

In the repository settings, open **Pages**, choose **Deploy from a branch**, select the `main` branch and `/ (root)`, then save.

No build step or dependencies are required.
